# 판촉물 관리대장

팀이 함께 쓰는 판촉물 재고·입고·출고 관리 페이지입니다. Claude 계정 없이 웹 주소와 비밀번호만으로 PC·모바일에서 사용합니다.

- 화면: GitHub Pages (이 저장소)
- 데이터: 구글 스프레드시트 (Google Apps Script 웹 앱)
- 권한: 팀 비밀번호(조회·출고 등록/수정/삭제), 관리자 비밀번호(입고, 출고자 명단, 변경 이력)

## 처음 한 번만 하는 설정

### 1. 구글 시트 + Apps Script
1. [sheets.new](https://sheets.new) 에서 새 스프레드시트를 만들고 이름을 `판촉물 관리대장 데이터` 로 바꿉니다.
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 기본 코드를 모두 지우고 `apps-script/Code.gs` 내용을 붙여넣습니다.
4. 맨 위 `TEAM_PASSWORD`, `ADMIN_PASSWORD` 두 값을 원하는 비밀번호로 바꾸고 저장(💾)합니다.
5. 위쪽 함수 선택 칸에서 `setup` 을 고르고 **실행** → 권한 승인(내 계정 선택 → 고급 → 이동 → 허용).
   시트에 `품목 / 입고 / 출고 / 설정 / 변경이력` 탭이 생기고 기존 데이터가 들어갑니다.
6. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 실행 계정: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포** → 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`) 을 복사합니다.

### 2. 웹 앱 주소 넣기
`config.js` 의 `window.PROMO_API_URL = '';` 따옴표 안에 위 주소를 넣고 저장(커밋)합니다.

### 3. GitHub Pages 켜기
저장소 **Settings → Pages → Build and deployment**
- Source: **Deploy from a branch**
- Branch: **main** / **/(root)** → **Save**

1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소로 열립니다. 이 주소와 팀 비밀번호를 팀원에게 공유하세요.

## 코드를 고친 뒤 (Apps Script)
`Code.gs` 를 바꿨다면 **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포** 를 해야 반영됩니다. 웹 앱 주소는 그대로 유지됩니다.

## 참고
- 데이터 원본은 구글 시트에 있습니다. 시트는 공유하지 않아도 됩니다(웹 앱이 대신 읽고 씁니다).
- 비밀번호를 바꾸려면 `Code.gs` 의 값을 바꾸고 새 버전으로 배포하세요. 팀원은 다시 로그인하게 됩니다.
